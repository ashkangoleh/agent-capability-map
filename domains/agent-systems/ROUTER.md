# Agent Systems Domain Router

Use for agent architecture, tool use, MCP integration, skill authoring, capability maps, routing, orchestration, and agent evaluation.

1. Read domains/agent-systems/skills.json only.
2. Creating, reviewing, or validating SKILL.md files, registries, and routing policies routes to skill-authoring-validation.
3. Building a RAG application or retrieval pipeline routes to ai-ml unless the main deliverable is the agent runtime or capability system.
4. Prefer deterministic registries and file-based routing while the map is small.
5. Do not add vector search, graph databases, or multi-agent orchestration without measured evidence that simpler routing is insufficient.
6. Verify target-client behavior. AGENTS.md, custom routers, and Agent Skills loaders are not interchangeable.
