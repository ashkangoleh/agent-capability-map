# curriculum-outcomes-assessment: specialist evaluation and negative controls

Domain `education/core`. This is a **proposed** evidence plan, never a real-system test result or execution permission.

## Specialist required inputs
Verify specialist prerequisites against real artifacts.

## Preserve skill-specific method
1. Define observable learning outcomes and prerequisites; separate knowledge recall from application and transfer.
2. Map each outcome to an instructional activity and evidence of mastery; avoid untestable verbs without criteria.
3. Sequence learning from prerequisite concepts to practice, feedback and independent application.
4. Build diagnostic, formative and summative checks with answer keys or scoring rubrics; avoid testing skills not taught.

## Challenge / acceptance
- **Challenge:** Use a misleading or inaccessible assessment item. Exercise an authorized contradictory, missing or adversarial test input.
- **Independent oracle:** Learner outcomes and accessibility verified by independent assessment evidence. Reconcile observed outcomes against a fixed control; do not use the generated answer as its own oracle.
- **Existing failure risks:** Unknown evidence remains UNKNOWN.
- **Stop/review:** No certification, learning benefit or learner diagnosis without validated evidence. Stop at incomplete authorizations, uncertain authoritative sources and irreversible changes.

## Acceptance evidence ledger
- [ ] Real source artifacts, version/effective date, scope, owner, permissions and lower-trust input boundary recorded.
- [ ] At least one baseline, negative control, ambiguity/near miss and recovery/retraction test documented with falsifiable expected outcomes.
- [ ] Domain-specific result, affected population, uncertainty, metrics and policy constraints independently verified.
- [ ] For implementation: isolated executable compatibility/failure tests, side effects and rollback. For advisory work: qualified independent review and citation audit instead.
- [ ] Simpler alternative, operational cost, incident/escalation owner and explicitly unresolved uncertainties stated.
- [ ] Separate proposed test from executed evidence; never claim production, legal, medical, security or regulatory certification from CI.
