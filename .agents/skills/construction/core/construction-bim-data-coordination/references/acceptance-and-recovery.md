# construction-bim-data-coordination: specialist evaluation and negative controls

Domain `construction/core`. This is a **proposed** evidence plan, never a real-system test result or execution permission.

## Specialist required inputs
Verify specialist prerequisites against real artifacts.

## Preserve skill-specific method
1. Confirm model purpose, IFC release and authoring/export version before applying schema assumptions.
2. Review global IDs, building levels, spaces, classifications and property/quantity sets with specified exchange requirements.
3. Check unit systems, coordinate reference and model placement before calculating differences or clashes.
4. Distinguish geometry validity from information completeness and contractual compliance.

## Challenge / acceptance
- **Challenge:** Modify a critical design constraint or construction sequence. Exercise an authorized contradictory, missing or adversarial test input.
- **Independent oracle:** Reconciled quantities, safety assumptions, affected work packages and qualified approvals are traceable. Reconcile observed outcomes against a fixed control; do not use the generated answer as its own oracle.
- **Existing failure risks:** Unknown evidence remains UNKNOWN.
- **Stop/review:** No structural safety signoff or site instruction without licensed review. Stop at incomplete authorizations, uncertain authoritative sources and irreversible changes.

## Acceptance evidence ledger
- [ ] Real source artifacts, version/effective date, scope, owner, permissions and lower-trust input boundary recorded.
- [ ] At least one baseline, negative control, ambiguity/near miss and recovery/retraction test documented with falsifiable expected outcomes.
- [ ] Domain-specific result, affected population, uncertainty, metrics and policy constraints independently verified.
- [ ] For implementation: isolated executable compatibility/failure tests, side effects and rollback. For advisory work: qualified independent review and citation audit instead.
- [ ] Simpler alternative, operational cost, incident/escalation owner and explicitly unresolved uncertainties stated.
- [ ] Separate proposed test from executed evidence; never claim production, legal, medical, security or regulatory certification from CI.
