# sports-training-evidence-plan: specialist evaluation and negative controls

Domain `sports/core`. This is a **proposed** evidence plan, never a real-system test result or execution permission.

## Specialist required inputs
Verify specialist prerequisites against real artifacts.

## Preserve skill-specific method
1. Define performance goal, timeline and baseline without estimating individual physiology from appearance.
2. Build a gradual progression of frequency, intensity, duration and recovery consistent with population guidance, not a universal program.
3. Separate strength, endurance, skill and mobility work, using the sport's actual demands and time budget.
4. Plan warm-up, rest, fatigue monitoring and conservative progression; stop or refer for concerning symptoms.

## Challenge / acceptance
- **Challenge:** Change sport rules, sample cohort or instrument calibration. Exercise an authorized contradictory, missing or adversarial test input.
- **Independent oracle:** Performance claims match official event rules and valid denominators. Reconcile observed outcomes against a fixed control; do not use the generated answer as its own oracle.
- **Existing failure risks:** Unknown evidence remains UNKNOWN.
- **Stop/review:** No guaranteed athletic outcome or medical performance recommendation. Stop at incomplete authorizations, uncertain authoritative sources and irreversible changes.

## Acceptance evidence ledger
- [ ] Real source artifacts, version/effective date, scope, owner, permissions and lower-trust input boundary recorded.
- [ ] At least one baseline, negative control, ambiguity/near miss and recovery/retraction test documented with falsifiable expected outcomes.
- [ ] Domain-specific result, affected population, uncertainty, metrics and policy constraints independently verified.
- [ ] For implementation: isolated executable compatibility/failure tests, side effects and rollback. For advisory work: qualified independent review and citation audit instead.
- [ ] Simpler alternative, operational cost, incident/escalation owner and explicitly unresolved uncertainties stated.
- [ ] Separate proposed test from executed evidence; never claim production, legal, medical, security or regulatory certification from CI.
